learning path

From register writes to integrated peripherals.

The repository stays deliberately close to the metal. This path keeps the editing, building, simulation, and flashing rhythm visible while you move through each concept.

01 / editKeep F_CPU before AVR headers and preserve the lesson's register-first style.
02 / buildRun make create inside a lesson directory to produce the HEX file.
03 / simulateOpen the matching Proteus file and attach the generated HEX to the MCU.
04 / flashUse make upload when hardware is connected and the serial port is ready.
